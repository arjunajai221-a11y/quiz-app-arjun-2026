# Quiz Application

A simple and interactive Quiz Application developed using HTML, CSS, and JavaScript. Users can test their knowledge through multiple-choice questions and view their final scores.

## Features

- 10 multiple-choice questions
- Interactive answer selection
- Instant correct and incorrect answer feedback
- Real-time score tracking
- Progress bar
- Final score and percentage display
- Restart quiz option
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Quiz_Application/

```

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/arjunajai221-a11y/quiz-app-arjun-2026.git
```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or your web browser.

To practise frontend web development concepts, JavaScript fundamentals, DOM manipulation, and event handling by building an interactive quiz application.
